# 🌟 حور تلعب و تتعلم | Hoor Plays & Learns (v2.4.0)

لعبة تعليمية تفاعلية باللغة العربية مصممة للأطفال، تعمل مراحلها الأساسية دون اتصال بعد تحميلها على الويب وأجهزة الأندرويد الحديثة بصيغة **APK**.

---

## ✨ المميزات الرئيسية (Key Features)

1. **٢٠ مرحلة متدرجة عبر ٤ عوالم طبيعية:**
   - 🌾 **مزرعة الفجر الهادئة** (المراحل ١ - ٥)
   - 🌳 **غابة الندى الخضراء** (المراحل ٦ - ١٠)
   - ⛰️ **تلال الشفق الذهبي** (المراحل ١١ - ١٥)
   - 🏰 **قلعة السحاب السعيدة** (المراحل ١٦ - ٢٠)
2. **واحة القرآن الكريم والتدبر بين المراحل:**
   - بعد إتمام كل مرحلة، تظهر آية قرآنية كريمة مع تفسير مبسط. نص الآية متاح دون اتصال؛ أما التلاوة الصوتية فتحتاج اتصالاً عند تشغيلها أول مرة، ويحاول تطبيق الويب حفظ المقاطع التي تم تشغيلها لتتاح لاحقاً دون اتصال (قد يمسحها المتصفح عند الحاجة للمساحة).
3. **تحدي الأذكياء التعليمي لحور (عمر ٦ سنوات):**
   - أسئلة تفاعلية بين المراحل تشمل **الجمع البسيط**، **الطرح البسيط**، و**الكلمات الإنجليزية المصورة** مع وسائل عدّ بصرية لمساعدة الطفل على التعلم الذاتي.
4. **مؤثرات صوتية طبيعية ١٠٠٪ (بدون أي موسيقى):**
   - محرك صوتيات `Web Audio API` يولّد أصوات عصافير، نقرات خشبية دافئة، وفقاعات ماء طبيعية خالية تماماً من المعزوفات الموسيقية.
5. **تطبيق أندرويد (APK) يعمل دون اتصال:**
   - حزمة `Hoor-Plays-Learns.apk` تضم اللعبة الأساسية والأصول محلياً. التلاوات الصوتية الخارجية لا تُضمن دون اتصال في APK.
6. **ملفات أطفال ونسخ احتياطي محلية:**
   - يمكن حفظ تقدم وإعدادات منفصلة لكل طفل على الجهاز، وتصدير أو استيراد نسخة JSON يدوياً لنقل البيانات أو استعادتها.

## 🛠️ طريقة التشغيل والبناء محلياً (Local Development & Build)

### ١. تثبيت الحزم وتشغيل بيئة التطوير:
```bash
npm install
npm run dev
```

### ٢. بناء نسخة الويب + ملف HTML المحمول + تطبيق الأندرويد APK:
```bash
npm run release
```
أو خطوة بخطوة:
```bash
# 1. بناء تطبيق الويب (Vite + PWA)
npm run build

# 2. توليد ملف اللعبة المحمول المدمج بالكامل (HTML أوفلاين)
npm run bundle:html

# 3. بناء وتوقيع تطبيق الأندرويد (APK) ومشروع Android Studio
npm run build:apk
```

## 📦 الملفات الناتجة بعد البناء (Build Outputs)

- `public/Hoor-Plays-Learns.apk`: ملف تطبيق الأندرويد النهائي الموقّع (v1/v2/v3) الجاهز للتثبيت على جميع الهواتف والأجهزة اللوحية.
- `public/Hoor-Plays-Learns-Android.html`: ملف واحد مستقل (Single-File Bundle) يحتوي على اللعبة مع صورة حور؛ اللعب الأساسي يعمل دون اتصال، أما التلاوات الصوتية الخارجية فلا تُضمن في هذا الملف.
- `public/Hoor-Android-APK-Project.zip`: مشروع Android Studio الكامل مع الكود المصدري بلغة Java (`MainActivity.java`).

## 🔄 الاختبار والبناء التلقائي عبر GitHub Actions

يحتوي المستودع على ملف `.github/workflows/build-and-deploy.yml` الذي يشغّل الاختبارات وفحص TypeScript ويبني ملفات الويب وAPK عند كل تحديث للفرعين `main` أو `master`. تُرفق نواتج Android في **Actions Artifacts**؛ لا ينشر هذا السير الموقع على GitHub Pages.
